# Brand artwork

Generated with Codex's built-in image generation tool on 2026-09-13. These are original promotional illustrations, not product screenshots. The examples in `docs/examples/` are rendered by the application with synthetic data.

`hero.png` is the original. `social-preview.jpg` is the same artwork resized to 1280 × 640 and encoded as JPEG with macOS `sips` for GitHub's upload limit. `icon.png` is the original generated icon.

## Hero prompt

```text
Use case: ads-marketing
Asset type: GitHub open-source project hero banner and social preview, wide 2:1 aspect ratio.
Primary request: Design finished original brand artwork for an independent developer tool named "Codex Usage Reports" that automatically shows per-task and per-turn token usage. Refined editorial tech design, credible open-source software, sophisticated restraint.
Scene: deep ink navy background with subtle print grain. At the right, an elegant sculptural stack of thin translucent pale mint report sheets; precise coral timeline markers and delicate warm-white metric lines on the sheets symbolize individual turns accumulating into a task. These are abstract art, no fake product screenshot, no numerical claims. Flat front-on layout with dimensional paper depth only in the right illustration.
Typography: beautifully typeset warm white sans serif, large title across the left 60%, exact text "Codex Usage Reports". Two lines for the title permitted. Below in smaller mint text: "Every task. Every turn." At the lower left a very small uppercase descriptor "LOCAL • OPEN SOURCE".
Composition: strong aligned margins, ample negative space, excellent readability at small GitHub README widths, complete text inset at least 8% from all edges. Keep entire art inside canvas.
Avoid: OpenAI logo, robot, mascot, circuit-board cliches, excessive glow, illegible tiny text, fabricated graphs, numerical statistics, app window chrome, watermarks. This is a community project, no official endorsement.
```
