# Documentation

[Main README](../README.md) · [繁體中文](i18n/README.zh-TW.md) · [简体中文](i18n/README.zh-CN.md) · [日本語](i18n/README.ja.md)

Codex Usage Reports is the independent, report-only plugin in this repository. Start with the [quick start](../README.md#quick-start). The guides below separate everyday use, observed data, optional activity, updates, and maintenance.

## Use the plugin

| Need | Guide |
| --- | --- |
| Install, configure, select a Task, export a report, choose a language, or remove the plugin | [Usage and CLI](USAGE.md) |
| Interpret parent, turn, child, cache, and quota numbers or partial status | [Metrics](METRICS.md) |
| See synthetic cards, receipts, and downloadable HTML | [Example gallery](examples/README.md) |
| Diagnose missing cards, unavailable counters, or hook trust | [Troubleshooting](TROUBLESHOOTING.md) |
| Keep Codex Run Budget controls while moving automatic reports | [Migration](MIGRATION.md) |

## Optional capabilities

| Need | Guide |
| --- | --- |
| Observe one project's extra `codex exec` sessions or wrap an ephemeral run | [Project exec activity](EXEC_ACTIVITY.md) |
| Understand signed automatic runtime updates, Task pinning, controls, and rollback | [Signed updates](SIGNED_UPDATES.md) |
| Check installed package versions and native hook trust or understand reminder notices | [Update notices](UPDATE_NOTICES.md) |

## Maintain or review the project

| Need | Guide |
| --- | --- |
| Understand lifecycle, source lanes, completion reconciliation, and external seams | [Architecture](ARCHITECTURE.md) |
| Reproduce checks and read dated compatibility evidence | [Validation](VALIDATION.md) |
| Contribute and keep translations or synthetic assets current | [Contributing](../CONTRIBUTING.md) |
| Handle local data, publisher trust, or security reports | [Security](../SECURITY.md) |
| Read release history | [Changelog](../CHANGELOG.md) |

The dated results in [validation](VALIDATION.md) describe the versions tested at the time. They do not establish the state of a current installation.
